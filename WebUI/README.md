# Temi机器人Web控制界面使用指南

## 快速开始

### 1. 安装依赖

```bash
pip install Flask==2.3.0
```

或使用requirements文件：
```bash
pip install -r requirements_web.txt
```

### 2. 运行Web服务器

```bash
python web_ui.py
```

### 3. 访问界面

打开浏览器访问：
- 本机访问: http://localhost:5000
- 局域网访问: http://<你的IP地址>:5000 (例如: http://192.168.8.132:5000)

## 功能说明

### 主要功能
1. **连接管理**
   - 一键连接/断开机器人
   - 实时显示连接状态

2. **状态监控**
   - 机器人运行状态
   - 导航状态
   - 当前操作显示

3. **控制功能**
   - 开始巡航（按waypoints.txt文件）
   - 前往指定路点
   - 停止机器人

4. **路点管理**
   - 显示所有可用路点
   - 点击路点直接导航

5. **照片查看**
   - 显示最近拍摄的照片
   - 点击查看大图

## 部署选项

### 选项1: 本地运行（最简单）
```bash
python web_ui.py
```
- 适合开发和测试
- 访问: http://localhost:5000

### 选项2: 局域网访问
```bash
python web_ui.py
```
- 自动监听0.0.0.0:5000
- 局域网内其他设备可通过IP访问
- 例如: http://192.168.8.132:5000

### 选项3: 生产环境部署（可选）

如需长期稳定运行，可使用Gunicorn:

1. 安装Gunicorn:
```bash
pip install gunicorn
```

2. 运行:
```bash
gunicorn -w 1 -b 0.0.0.0:5000 web_ui:app
```

参数说明:
- `-w 1`: 1个worker进程（避免全局变量冲突）
- `-b 0.0.0.0:5000`: 监听所有接口的5000端口

### 选项4: Windows后台服务（可选）

创建批处理文件 `start_web_ui.bat`:
```batch
@echo off
cd /d "%~dp0"
python web_ui.py
pause
```

## 技术架构

```
Frontend (HTML/CSS/JS)
    ↓ AJAX请求
Flask Web Server (web_ui.py)
    ↓ 调用
Temi_Control_Def (temi_control.py)
    ↓ MQTT
Temi机器人
```

## 注意事项

1. **防火墙**: 确保5000端口未被防火墙阻止
2. **网络**: Web服务器和机器人需在同一网络
3. **并发**: 当前版本不支持多用户同时控制
4. **照片**: 照片存储在photos目录，定期清理以节省空间

## 故障排查

### 问题1: 无法访问Web界面
- 检查Flask是否正常启动
- 确认5000端口未被占用
- 检查防火墙设置

### 问题2: 无法连接机器人
- 确认MQTT服务器IP正确
- 检查机器人是否在线
- 查看waypoints.txt文件是否存在

### 问题3: 照片无法显示
- 确认photos目录存在
- 检查照片文件权限
- 查看浏览器控制台错误

## 自定义配置

编辑 `web_ui.py` 文件:

```python
# 修改默认配置
BROKER_IP = "192.168.8.xxx"  # MQTT服务器IP
TEMI_SERIAL = "你的机器人序列号"  # 机器人序列号

# 修改端口
app.run(host='0.0.0.0', port=8080)  # 改为8080端口
```
